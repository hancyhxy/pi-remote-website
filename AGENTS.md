# heyatu-marketing

Hey Atu marketing and brand work, owned by Xinyi. Read `README.md` first.

- Scope: `brand/`, `docs/`. `website/` links to `../pi-remote/site`: a change
  there is a `pi-remote` change, so follow `../pi-remote/AGENTS.md` and
  `website/README.md`. Leave the rest of `../pi-remote` to the product team.
- `brand/mascot/app-current/` mirrors the shipped app; replace it only with
  files the app ships.
- `archive/` is history; change it only on request.
- Deploy only on an explicit user request. A push is a backup; the GitHub
  Pages copy of `archive/site-v1-pi-remote/` publishes only on a manual run
  of `.github/workflows/pages.yml`.
- Remote: `origin` = private `hancyhxy/pi-remote-website`. Add no other
  remote without approval.
